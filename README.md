# alu-system_engineering-devops

System engineering and DevOps projects.

## ssh

- `0-use_a_private_key`: connects to a server as `ubuntu` using the
  private key `~/.ssh/school`.
- `1-create_ssh_key_pair`: creates a 4096-bit RSA key pair named `school` with passphrase `betty`.
- `2-ssh_config`: SSH client config that uses `~/.ssh/school` and refuses password authentication.
