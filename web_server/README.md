# web_server

- `0-transfer_file`: transfers a file to a server's home directory with
  `scp`. Usage: `./0-transfer_file PATH_TO_FILE IP USERNAME PATH_TO_SSH_KEY`
- `2-setup_a_domain_name`: contains the .tech domain pointing to web-01.
- `3-redirection`: installs nginx and sets a 301 redirect for `/redirect_me`.
